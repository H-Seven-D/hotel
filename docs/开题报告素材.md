# 开题报告素材

## 一、拟定题目

yeu 民宿酒店预订系统的设计与实现

## 二、研究背景

民宿和中小型酒店的业务具有房量适中、人员协作频繁、状态变化快等特点。传统表格和聊天工具难以同时维护房态、订单、客户、入住退房和员工排班，容易出现重复预订、责任不清和统计困难等问题。开发一套面向中小型住宿业务的管理系统具有现实应用价值。

## 三、研究目标

设计并实现一套前后端分离的民宿酒店预订管理系统，满足普通员工日常业务管理需求，并为管理员提供员工账号管理和操作审计能力。系统应当具备清晰的权限边界、可靠的预订冲突校验、完整的房态状态流转和可展示的运营统计。

## 四、主要研究内容

1. 分析民宿和中小型酒店的业务流程与角色需求。
2. 设计门店、房型、房间、客户、预订、排班和审计数据模型。
3. 使用 Spring Boot 和 MyBatis-Plus 实现后端业务接口。
4. 使用 Spring Security、JWT 和 BCrypt 实现认证与授权。
5. 使用 AOP 实现关键业务操作日志。
6. 使用 Vue 3、Element Plus 和 ECharts 实现蓝白色管理端。
7. 完成数据库脚本、接口文档、系统测试和论文材料。

## 五、拟解决的关键问题

- 如何通过日期区间校验避免同一房间重复预订。
- 如何设计普通员工与管理员的权限边界。
- 如何记录员工上线、下线和业务操作。
- 如何保证房间、预订和入住状态之间的一致性。
- 如何在删除员工、客户、房间等数据时保护历史业务记录。
- 如何用图表直观展示入住率、预订趋势和营收。

## 六、研究方法

### 6.1 文献分析法

查阅酒店管理系统、民宿预订平台、Java Web 和软件工程相关文献，归纳常见业务模块与设计方法。

### 6.2 需求分析法

从普通员工和管理员两类用户视角梳理业务场景，明确功能需求、权限需求和非功能需求。

### 6.3 原型设计法

先完成页面布局、状态标签、列表结构和表单交互原型，再进行接口和页面联调。

### 6.4 工程实现法

采用 Spring Boot 与 Vue 3 完成前后端分离开发，通过 MySQL 保存业务数据，通过 JWT 和 Spring Security 实现认证授权。

### 6.5 测试验证法

对登录、权限、预订、入住退房、排班和审计等核心功能进行接口测试和页面测试。

## 七、技术路线

```text
需求分析
  ↓
数据库与权限模型设计
  ↓
后端接口与业务规则实现
  ↓
前端页面与交互实现
  ↓
前后端联调
  ↓
功能测试与论文撰写
```

## 八、预期成果

1. 可运行的民宿酒店预订管理系统。
2. MySQL 建库建表脚本和初始化演示数据。
3. Swagger 接口文档。
4. 蓝白色管理端页面。
5. 系统测试记录。
6. 毕业设计说明书和答辩演示材料。

## 九、项目创新点与特色

- 将普通业务与管理员审计能力分层设计。
- 登录会话与 JWT 双重校验，退出后旧令牌失效。
- 通过 Spring AOP 统一记录关键业务操作。
- 房态、预订、入住和退房形成完整状态闭环。
- 同时提供房态分布、入住率、预订趋势和营收展示。

## 十二、开题答辩可说明的重点

1. 项目不是简单的信息增删改查，而是包含预订、入住、退房、清洁和排班的状态闭环。
2. 普通员工与管理员权限不是只体现在菜单隐藏，而是由后端安全配置强制执行。
3. 系统能够记录员工登录时间、下线时间、IP 和关键业务操作，满足管理追踪需求。
4. 项目已经具备真实数据库、可执行后端、前端生产构建和接口联调基础，可继续进入论文完善阶段。
